1. নীচের দ্বিঘাত সমীকরণের বীজদ্বয়ের প্রকৃতি লিখি—

নিয়ম: $ax^2 + bx + c = 0$ সমীকরণের নিরূপক $\Delta = b^2 - 4ac$।
যদি $\Delta > 0$ হয়, বীজদ্বয় বাস্তব ও অসমান। যদি $\Delta = 0$ হয়, বাস্তব ও সমান। যদি $\Delta < 0$ হয়, কোনো বাস্তব বীজ নেই।

(i) $2x^2+7x+3=0$
সমাধান

এখানে $a = 2, b = 7, c = 3$

নিরূপক ($\Delta$) $= b^2 - 4ac = 7^2 - 4(2)(3) = 49 - 24 = 25$

যেহেতু নিরূপক ধনাত্মক ($25 > 0$), তাই বীজদ্বয় বাস্তব এবং অসমান হবে।

উত্তর: বাস্তব ও অসমান।
(ii) $3x^2-2\sqrt{6}x+2=0$
সমাধান

এখানে $a = 3, b = -2\sqrt{6}, c = 2$

নিরূপক ($\Delta$) $= (-2\sqrt{6})^2 - 4(3)(2) = (4 \times 6) - 24 = 24 - 24 = 0$

যেহেতু নিরূপক শূন্য ($\Delta = 0$), তাই বীজদ্বয় বাস্তব এবং সমান হবে।

উত্তর: বাস্তব ও সমান।
(iii) $2x^2-7x+9=0$
সমাধান

এখানে $a = 2, b = -7, c = 9$

নিরূপক ($\Delta$) $= (-7)^2 - 4(2)(9) = 49 - 72 = -23$

যেহেতু নিরূপক ঋণাত্মক ($-23 < 0$), তাই সমীকরণটির কোনো বাস্তব বীজ নেই।

উত্তর: কোনো বাস্তব বীজ নেই।
(iv) $\displaystyle \frac{2}{5}x^2-\frac{2}{3}x+1=0$
সমাধান

এখানে $\displaystyle a = \frac{2}{5}, b = -\frac{2}{3}, c = 1$

নিরূপক ($\Delta$) $= \displaystyle \left(-\frac{2}{3}\right)^2 - 4\left(\frac{2}{5}\right)(1) = \frac{4}{9} - \frac{8}{5}$

$\displaystyle = \frac{20 - 72}{45} = -\frac{52}{45}$

যেহেতু নিরূপক ঋণাত্মক, তাই সমীকরণটির কোনো বাস্তব বীজ নেই।

উত্তর: কোনো বাস্তব বীজ নেই।

2. k-এর কোন্ মান/মানগুলির জন্য নীচের প্রতিটি দ্বিঘাত সমীকরণের বাস্তব ও সমান বীজ থাকবে হিসাব করে লিখি—

নিয়ম: বাস্তব ও সমান বীজ থাকার শর্ত হলো নিরূপক ($b^2 - 4ac$) = 0 হতে হবে।

(i) $49x^2+kx+1=0$
সমাধান

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} k^2 - 4(49)(1) = 0 \\ k^2 - 196 = 0 \\ k^2 = 196 \\ k = \pm \sqrt{196} = \pm 14 \end{array} \]
উত্তর: k = 14 অথবা -14
(ii) $3x^2-5x+2k=0$
সমাধান

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} (-5)^2 - 4(3)(2k) = 0 \\ 25 - 24k = 0 \\ 24k = 25 \\ k = \frac{25}{24} \end{array} \]
উত্তর: k = $\displaystyle\frac{25}{24}$
(iii) $9x^2-24x+k=0$
সমাধান

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} (-24)^2 - 4(9)(k) = 0 \\ 576 - 36k = 0 \\ 36k = 576 \\ k = \frac{576}{36} = 16 \end{array} \]
উত্তর: k = 16
(iv) $2x^2+3x+k=0$
সমাধান

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} 3^2 - 4(2)(k) = 0 \\ 9 - 8k = 0 \\ 8k = 9 \\ k = \frac{9}{8} \end{array} \]
উত্তর: k = $\displaystyle\frac{9}{8}$
(v) $x^2-2(5+2k)x+3(7+10k)=0$
সমাধান

এখানে $a = 1$, $b = -2(5+2k)$, $c = 3(7+10k)$

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} [-2(5+2k)]^2 - 4(1)[3(7+10k)] = 0 \\ 4(25 + 20k + 4k^2) - 12(7 + 10k) = 0 \end{array} \]

উভয়পক্ষকে 4 দিয়ে ভাগ করে পাই:

\[ \begin{array}{l} (25 + 20k + 4k^2) - 3(7 + 10k) = 0 \\ 4k^2 + 20k + 25 - 21 - 30k = 0 \\ 4k^2 - 10k + 4 = 0 \\ 2k^2 - 5k + 2 = 0 \quad [\text{2 দিয়ে ভাগ করে}] \end{array} \]

উৎপাদকে বিশ্লেষণ করে পাই:

\[ \begin{array}{l} 2k^2 - 4k - k + 2 = 0 \\ 2k(k - 2) - 1(k - 2) = 0 \\ (k - 2)(2k - 1) = 0 \end{array} \]

হয় $k = 2$, অথবা $k = \displaystyle\frac{1}{2}$

উত্তর: k = 2 অথবা $\displaystyle\frac{1}{2}$
(vi) $(3k+1)x^2+2(k+1)x+k=0$
সমাধান

শর্তানুসারে, নিরূপক = 0

\[ \begin{array}{l} [2(k+1)]^2 - 4(3k+1)(k) = 0 \\ 4(k^2 + 2k + 1) - 4(3k^2 + k) = 0 \end{array} \]

উভয়পক্ষকে 4 দিয়ে ভাগ করে পাই:

\[ \begin{array}{l} (k^2 + 2k + 1) - (3k^2 + k) = 0 \\ k^2 + 2k + 1 - 3k^2 - k = 0 \\ -2k^2 + k + 1 = 0 \\ 2k^2 - k - 1 = 0 \quad [\text{(-1) দিয়ে গুণ করে}] \end{array} \]

উৎপাদকে বিশ্লেষণ করে পাই:

\[ \begin{array}{l} 2k^2 - 2k + k - 1 = 0 \\ 2k(k - 1) + 1(k - 1) = 0 \\ (k - 1)(2k + 1) = 0 \end{array} \]

হয় $k = 1$, অথবা $k = -\displaystyle\frac{1}{2}$

উত্তর: k = 1 অথবা $-\displaystyle\frac{1}{2}$

3. নীচে প্রদত্ত বীজদ্বয় দ্বারা দ্বিঘাত সমীকরণ গঠন করি—

নিয়ম: বীজদ্বয় $\alpha$ ও $\beta$ হলে নির্ণেয় সমীকরণ: $x^2 - (\alpha+\beta)x + \alpha\beta = 0$

(i) 4, 2
সমাধান

বীজদ্বয়ের সমষ্টি = $4 + 2 = 6$

বীজদ্বয়ের গুণফল = $4 \times 2 = 8$

নির্ণেয় দ্বিঘাত সমীকরণ: $x^2 - (\text{সমষ্টি})x + (\text{গুণফল}) = 0$

উত্তর: $x^2 - 6x + 8 = 0$
(ii) -4, -3
সমাধান

বীজদ্বয়ের সমষ্টি = $-4 + (-3) = -7$

বীজদ্বয়ের গুণফল = $(-4) \times (-3) = 12$

নির্ণেয় দ্বিঘাত সমীকরণ: $x^2 - (-7)x + 12 = 0$

উত্তর: $x^2 + 7x + 12 = 0$
(iii) -4, 3
সমাধান

বীজদ্বয়ের সমষ্টি = $-4 + 3 = -1$

বীজদ্বয়ের গুণফল = $(-4) \times 3 = -12$

নির্ণেয় দ্বিঘাত সমীকরণ: $x^2 - (-1)x + (-12) = 0$

উত্তর: $x^2 + x - 12 = 0$
(iv) 5, -3
সমাধান

বীজদ্বয়ের সমষ্টি = $5 + (-3) = 2$

বীজদ্বয়ের গুণফল = $5 \times (-3) = -15$

নির্ণেয় দ্বিঘাত সমীকরণ: $x^2 - (2)x + (-15) = 0$

উত্তর: $x^2 - 2x - 15 = 0$

4. m-এর মান কত হলে, $4x^2+4(3m-1)x+(m+7)=0$ দ্বিঘাত সমীকরণের বীজ দুটি পরস্পর অন্যোন্যক হবে।

সমাধান

ধরি, একটি বীজ $\alpha$। যেহেতু বীজ দুটি পরস্পর অন্যোন্যক (reciprocal), তাই অপর বীজটি হবে $\displaystyle\frac{1}{\alpha}$।

আমরা জানি, বীজদ্বয়ের গুণফল = $\displaystyle\frac{c}{a}$

\[ \begin{array}{l} \alpha \times \frac{1}{\alpha} = \frac{m+7}{4} \\ 1 = \frac{m+7}{4} \\ m + 7 = 4 \\ m = 4 - 7 = -3 \end{array} \]
উত্তর: m-এর নির্ণেয় মান -3

5. $(b-c)x^2+(c-a)x+(a-b)=0$ দ্বিঘাত সমীকরণের বীজদ্বয় সমান হলে, প্রমাণ করি যে, $2b=a+c$

সমাধান

যেহেতু সমীকরণটির বীজদ্বয় সমান, তাই নিরূপক = 0 হবে।

\[ \begin{array}{l} (c-a)^2 - 4(b-c)(a-b) = 0 \\ (c^2 - 2ca + a^2) - 4(ab - b^2 - ca + bc) = 0 \\ c^2 - 2ca + a^2 - 4ab + 4b^2 + 4ca - 4bc = 0 \\ a^2 + 4b^2 + c^2 - 4ab - 4bc + 2ca = 0 \end{array} \]

এটিকে আমরা বর্গের সূত্রে সাজাতে পারি:

\[ \begin{array}{l} (a)^2 + (-2b)^2 + (c)^2 + 2(a)(-2b) + 2(-2b)(c) + 2(c)(a) = 0 \\ ^2 = 0 \\ (a - 2b + c)^2 = 0 \\ a - 2b + c = 0 \\ a + c = 2b \end{array} \]
প্রমাণিত (Proved)।

6. $(a^2+b^2)x^2-2(ac+bd)x+(c^2+d^2)=0$ দ্বিঘাত সমীকরণের বীজদ্বয় সমান হলে, প্রমাণ করি যে, $\displaystyle\frac{a}{b}=\frac{c}{d}$

সমাধান

বীজদ্বয় সমান হওয়ায় নিরূপক = 0।

\[ \begin{array}{l} [-2(ac+bd)]^2 - 4(a^2+b^2)(c^2+d^2) = 0 \\ 4(a^2c^2 + 2abcd + b^2d^2) - 4(a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2) = 0 \end{array} \]

উভয়পক্ষকে 4 দিয়ে ভাগ করে পাই:

\[ \begin{array}{l} (a^2c^2 + 2abcd + b^2d^2) - a^2c^2 - a^2d^2 - b^2c^2 - b^2d^2 = 0 \\ 2abcd - a^2d^2 - b^2c^2 = 0 \\ -(a^2d^2 - 2abcd + b^2c^2) = 0 \\ a^2d^2 - 2(ad)(bc) + b^2c^2 = 0 \\ (ad - bc)^2 = 0 \\ ad - bc = 0 \\ ad = bc \end{array} \]

অতএব, $ad = bc \implies \displaystyle\frac{a}{b} = \frac{c}{d}$

প্রমাণিত (Proved)।

7. প্রমাণ করি যে, $2(a^2+b^2)x^2+2(a+b)x+1=0$ দ্বিঘাত সমীকরণের কোনো বাস্তব বীজ থাকবে না, যদি $a \neq b$ হয়।

সমাধান

কোনো বাস্তব বীজ না থাকার শর্ত হলো নিরূপক ঋণাত্মক ( < 0 ) হতে হবে।

প্রদত্ত সমীকরণের নিরূপক:

\[ \begin{array}{l} \Delta = [2(a+b)]^2 - 4[2(a^2+b^2)](1) \\ = 4(a^2+2ab+b^2) - 8(a^2+b^2) \\ = 4a^2 + 8ab + 4b^2 - 8a^2 - 8b^2 \\ = -4a^2 + 8ab - 4b^2 \\ = -4(a^2 - 2ab + b^2) \\ = -4(a - b)^2 \end{array} \]

যেহেতু $a \neq b$, তাই $(a - b)$ শূন্য নয় এবং যেকোনো বাস্তব সংখ্যার বর্গ সর্বদা ধনাত্মক হয়, অর্থাৎ $(a - b)^2 > 0$।

সুতরাং, $-4(a - b)^2$ সর্বদা ঋণাত্মক ($< 0$) হবে।

যেহেতু নিরূপক ঋণাত্মক, তাই সমীকরণটির কোনো বাস্তব বীজ থাকতে পারে না।

প্রমাণিত (Proved)।

8. $5x^2+2x-3=0$ দ্বিঘাত সমীকরণের দুটি বীজ $\alpha$ ও $\beta$ হলে মান নির্ণয় করি।

প্রদত্ত সমীকরণ: $5x^2 + 2x - 3 = 0$

বীজদ্বয়ের সমষ্টি: $\alpha + \beta = -\displaystyle\frac{b}{a} = -\frac{2}{5}$

বীজদ্বয়ের গুণফল: $\alpha\beta = \displaystyle\frac{c}{a} = -\frac{3}{5}$

(i) $\alpha^2+\beta^2$ -এর মান নির্ণয় করি।

আমরা জানি, $a^2 + b^2 = (a+b)^2 - 2ab$

\[ \begin{array}{l} \alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta \\ = \left(-\frac{2}{5}\right)^2 - 2\left(-\frac{3}{5}\right) \\ = \frac{4}{25} + \frac{6}{5} \\ = \frac{4 + 30}{25} = \frac{34}{25} = 1\frac{9}{25} \end{array} \]
উত্তর: $\displaystyle\frac{34}{25}$
(ii) $\alpha^3+\beta^3$ -এর মান নির্ণয় করি।

আমরা জানি, $a^3 + b^3 = (a+b)^3 - 3ab(a+b)$

\[ \begin{array}{l} \alpha^3 + \beta^3 = (\alpha+\beta)^3 - 3\alpha\beta(\alpha+\beta) \\ = \left(-\frac{2}{5}\right)^3 - 3\left(-\frac{3}{5}\right)\left(-\frac{2}{5}\right) \\ = -\frac{8}{125} - \frac{18}{25} \\ = \frac{-8 - 90}{125} = -\frac{98}{125} \end{array} \]
উত্তর: $\displaystyle-\frac{98}{125}$
(iii) $\displaystyle\frac{1}{\alpha}+\frac{1}{\beta}$ -এর মান নির্ণয় করি। \[ \begin{array}{l} \frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta} \\ = \frac{-\frac{2}{5}}{-\frac{3}{5}} = \frac{2}{5} \times \frac{5}{3} = \frac{2}{3} \end{array} \]
উত্তর: $\displaystyle\frac{2}{3}$
(iv) $\displaystyle\frac{\alpha^2}{\beta}+\frac{\beta^2}{\alpha}$ -এর মান নির্ণয় করি। \[ \begin{array}{l} \frac{\alpha^2}{\beta} + \frac{\beta^2}{\alpha} = \frac{\alpha^3 + \beta^3}{\alpha\beta} \end{array} \]

(ii) নং থেকে আমরা পেয়েছি, $\alpha^3 + \beta^3 = -\displaystyle\frac{98}{125}$

\[ \begin{array}{l} = \frac{-\frac{98}{125}}{-\frac{3}{5}} = \frac{98}{125} \times \frac{5}{3} \\ = \frac{98}{25 \times 3} = \frac{98}{75} = 1\frac{23}{75} \end{array} \]
উত্তর: $\displaystyle\frac{98}{75}$

9. $ax^2+bx+c=0$ সমীকরণটির একটি বীজ অপরটির দ্বিগুণ হলে, দেখাই যে, $2b^2=9ac$.

সমাধান

ধরি, সমীকরণটির একটি বীজ হলো $\alpha$।

শর্তানুসারে, অপর বীজটি হবে $2\alpha$।

বীজদ্বয়ের সমষ্টি: $\alpha + 2\alpha = -\displaystyle\frac{b}{a}$

\[ \begin{array}{l} 3\alpha = -\frac{b}{a} \\ \alpha = -\frac{b}{3a} \quad \text{--- (i)} \end{array} \]

বীজদ্বয়ের গুণফল: $\alpha \times 2\alpha = \displaystyle\frac{c}{a}$

\[ \begin{array}{l} 2\alpha^2 = \frac{c}{a} \quad \text{--- (ii)} \end{array} \]

এখন, (i) নং থেকে $\alpha$-এর মান (ii) নং এ বসিয়ে পাই:

\[ \begin{array}{l} 2 \left(-\frac{b}{3a}\right)^2 = \frac{c}{a} \\ 2 \left(\frac{b^2}{9a^2}\right) = \frac{c}{a} \\ \frac{2b^2}{9a^2} = \frac{c}{a} \\ 2b^2 = \frac{c \cdot 9a^2}{a} \\ 2b^2 = 9ac \end{array} \]
প্রমাণিত (Proved)।

10. যে সমীকরণের বীজগুলি $x^2+px+1=0$ সমীকরণের বীজগুলির অন্যোন্যক, সেই সমীকরণটি গঠন করি।

সমাধান

ধরি, $x^2 + px + 1 = 0$ সমীকরণের বীজ দুটি হলো $\alpha$ এবং $\beta$।

বীজদ্বয়ের সমষ্টি: $\alpha + \beta = -p$

বীজদ্বয়ের গুণফল: $\alpha\beta = 1$

নতুন সমীকরণের বীজগুলি হলো $\alpha$ ও $\beta$-এর অন্যোন্যক (reciprocal), অর্থাৎ $\displaystyle\frac{1}{\alpha}$ এবং $\displaystyle\frac{1}{\beta}$।

নতুন বীজদ্বয়ের সমষ্টি:

\[ \begin{array}{l} \frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta} = \frac{-p}{1} = -p \end{array} \]

নতুন বীজদ্বয়ের গুণফল:

\[ \begin{array}{l} \frac{1}{\alpha} \times \frac{1}{\beta} = \frac{1}{\alpha\beta} = \frac{1}{1} = 1 \end{array} \]

নির্ণেয় দ্বিঘাত সমীকরণটি হলো:

\[ \begin{array}{l} x^2 - (\text{বীজদ্বয়ের সমষ্টি})x + (\text{বীজদ্বয়ের গুণফল}) = 0 \\ x^2 - (-p)x + 1 = 0 \\ x^2 + px + 1 = 0 \end{array} \]
উত্তর: নির্ণেয় সমীকরণটি হলো $x^2 + px + 1 = 0$

11. $x^2+x+1=0$ সমীকরণটির বীজগুলির বর্গ যে সমীকরণের বীজ, সেই সমীকরণটি নির্ণয় করি।

সমাধান

ধরি, $x^2 + x + 1 = 0$ সমীকরণের বীজ দুটি হলো $\alpha$ এবং $\beta$।

$\alpha + \beta = -1$ এবং $\alpha\beta = 1$

নির্ণেয় সমীকরণের বীজগুলি হবে $\alpha^2$ এবং $\beta^2$।

নতুন বীজদ্বয়ের সমষ্টি:

\[ \begin{array}{l} \alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta \\ = (-1)^2 - 2(1) \\ = 1 - 2 = -1 \end{array} \]

নতুন বীজদ্বয়ের গুণফল:

\[ \begin{array}{l} \alpha^2 \times \beta^2 = (\alpha\beta)^2 \\ = (1)^2 = 1 \end{array} \]

নির্ণেয় দ্বিঘাত সমীকরণটি হলো:

\[ \begin{array}{l} x^2 - (\alpha^2 + \beta^2)x + (\alpha^2\beta^2) = 0 \\ x^2 - (-1)x + 1 = 0 \\ x^2 + x + 1 = 0 \end{array} \]
উত্তর: নির্ণেয় সমীকরণটি হলো $x^2 + x + 1 = 0$

13. সংক্ষিপ্ত উত্তরধর্মী প্রশ্ন (S.A.)

সমীকরণটি হলো: $x^2 - (\text{বীজদ্বয়ের সমষ্টি})x + (\text{বীজদ্বয়ের গুণফল}) = 0$

(ii) $kx^2+2x+3k=0 (k \neq 0)$ সমীকরণের বীজদ্বয়ের সমষ্টি এবং গুণফল সমান হলে, k-এর মান লিখি।
সমাধান

বীজদ্বয়ের সমষ্টি = $-\displaystyle\frac{2}{k}$

বীজদ্বয়ের গুণফল = $\displaystyle\frac{3k}{k} = 3$

(iii) $x^2-22x+105=0$ সমীকরণের বীজদ্বয় $\alpha$ এবং $\beta$ হলে, $(\alpha-\beta)$ -এর মান লিখি।
সমাধান

সমীকরণটিকে সাজিয়ে পাই:
