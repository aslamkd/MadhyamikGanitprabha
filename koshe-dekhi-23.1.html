ত্রিকোণমিতিক অনুপাতের প্রাথমিক ধারণা:
যেকোনো সমকোণী ত্রিভুজের একটি নির্দিষ্ট সূক্ষ্মকোণ ($\theta$)-এর সাপেক্ষে:
$\sin\theta = \displaystyle\frac{\text{লম্ব (Perpendicular)}}{\text{অতিভুজ (Hypotenuse)}}$
$\cos\theta = \displaystyle\frac{\text{ভূমি (Base)}}{\text{অতিভুজ}}$
$\tan\theta = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}}$
$\text{cosec}\theta = \displaystyle\frac{\text{অতিভুজ}}{\text{লম্ব}}$, $\sec\theta = \displaystyle\frac{\text{অতিভুজ}}{\text{ভূমি}}$, $\cot\theta = \displaystyle\frac{\text{ভূমি}}{\text{লম্ব}}$

1. একটি সমকোণী ত্রিভুজ ABC এঁকেছি যার অতিভুজ AB = 10 সেমি., ভূমি BC = 8 সেমি. এবং লম্ব AC = 6 সেমি.। $\angle ABC$-এর sine এবং tangent-এর মান নির্ণয় করি।

সমাধান

প্রদত্ত সমকোণী ত্রিভুজ $\triangle ABC$-তে, $\angle C = 90^\circ$।

$\angle ABC$ কোণের সাপেক্ষে:

  • লম্ব (Perpendicular) = AC = 6 সেমি.
  • ভূমি (Base) = BC = 8 সেমি.
  • অতিভুজ (Hypotenuse) = AB = 10 সেমি.

$\angle ABC$-এর $\text{sine}$ অর্থাৎ $\sin(\angle ABC) = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}}$

\[ \begin{array}{l} \sin(\angle ABC) = \frac{AC}{AB} \\ = \frac{6}{10} = \frac{3}{5} \end{array} \]

$\angle ABC$-এর $\text{tangent}$ অর্থাৎ $\tan(\angle ABC) = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}}$

\[ \begin{array}{l} \tan(\angle ABC) = \frac{AC}{BC} \\ = \frac{6}{8} = \frac{3}{4} \end{array} \]
উত্তর: $\sin(\angle ABC) = \displaystyle\frac{3}{5}$ এবং $\tan(\angle ABC) = \displaystyle\frac{3}{4}$।

2. সোমা একটি সমকোণী ত্রিভুজ ABC এঁকেছে যার $\angle ABC = 90^\circ$, AB = 24 সেমি. এবং BC = 7 সেমি.। হিসাব করে $\sin A, \cos A, \tan A$ ও $\text{cosec} A$-এর মান লিখি।

সমাধান

$\triangle ABC$-এ $\angle B = 90^\circ$, AB = 24 সেমি এবং BC = 7 সেমি।

পিথাগোরাসের উপপাদ্য অনুযায়ী অতিভুজ AC-এর দৈর্ঘ্য বের করি:

\[ \begin{array}{l} AC^2 = AB^2 + BC^2 \\ AC^2 = 24^2 + 7^2 \\ AC^2 = 576 + 49 = 625 \\ AC = \sqrt{625} = 25 \text{ সেমি.} \end{array} \]

$\angle A$-এর সাপেক্ষে:

ভূমি (Base) = কোণের ধারক বাহু = AB = 24 সেমি।

লম্ব (Perpendicular) = কোণের বিপরীত বাহু = BC = 7 সেমি।

অতিভুজ (Hypotenuse) = AC = 25 সেমি।


$\sin A = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{BC}{AC} = \frac{7}{25}$

$\cos A = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}} = \frac{AB}{AC} = \frac{24}{25}$

$\tan A = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}} = \frac{BC}{AB} = \frac{7}{24}$

$\text{cosec} A = \displaystyle\frac{\text{অতিভুজ}}{\text{লম্ব}} = \frac{AC}{BC} = \frac{25}{7}$

উত্তর: $\sin A = \frac{7}{25}$, $\cos A = \frac{24}{25}$, $\tan A = \frac{7}{24}$, $\text{cosec} A = \frac{25}{7}$।

3. যদি ABC সমকোণী ত্রিভুজের $\angle C = 90^\circ$, BC = 21 একক এবং AB = 29 একক হয়, তাহলে $\sin A, \cos A, \sin B$ ও $\cos B$-এর মান নির্ণয় করি।

সমাধান

$\triangle ABC$-এ $\angle C = 90^\circ$, অতিভুজ AB = 29 এবং বাহু BC = 21।

পিথাগোরাসের উপপাদ্য অনুযায়ী লম্ব AC-এর দৈর্ঘ্য বের করি:

\[ \begin{array}{l} AC^2 + BC^2 = AB^2 \\ AC^2 + 21^2 = 29^2 \\ AC^2 + 441 = 841 \\ AC^2 = 841 - 441 = 400 \\ AC = \sqrt{400} = 20 \text{ একক} \end{array} \]

$\angle A$-এর সাপেক্ষে:

লম্ব = BC = 21, ভূমি = AC = 20, অতিভুজ = AB = 29।

$\sin A = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{21}{29}$

$\cos A = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}} = \frac{20}{29}$

$\angle B$-এর সাপেক্ষে:

লম্ব = AC = 20 (যেহেতু $\angle B$-এর বিপরীত বাহু AC), ভূমি = BC = 21, অতিভুজ = AB = 29।

$\sin B = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{20}{29}$

$\cos B = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}} = \frac{21}{29}$

উত্তর: $\sin A = \frac{21}{29}$, $\cos A = \frac{20}{29}$, $\sin B = \frac{20}{29}$, $\cos B = \frac{21}{29}$।

4. যদি $\cos\theta = \displaystyle\frac{7}{25}$ হয়, তাহলে $\theta$ কোণের সকল ত্রিকোণমিতিক অনুপাতের মান নির্ণয় করি।

সমাধান

দেওয়া আছে, $\cos\theta = \displaystyle\frac{7}{25}$

আমরা জানি, $\cos\theta = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}}$।

ধরি, ভূমি $= 7k$ একক এবং অতিভুজ $= 25k$ একক (যেখানে $k > 0$)।

পিথাগোরাসের উপপাদ্য অনুযায়ী লম্ব-এর দৈর্ঘ্য নির্ণয় করি:

\[ \begin{array}{l} \text{লম্ব}^2 + \text{ভূমি}^2 = \text{অতিভুজ}^2 \\ \text{লম্ব}^2 + (7k)^2 = (25k)^2 \\ \text{লম্ব}^2 + 49k^2 = 625k^2 \\ \text{লম্ব}^2 = 625k^2 - 49k^2 = 576k^2 \\ \text{লম্ব} = \sqrt{576k^2} = 24k \text{ একক} \end{array} \]

এখন, $\theta$ কোণের বাকি ত্রিকোণমিতিক অনুপাতগুলি হলো:

  • $\sin\theta = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{24k}{25k} = \frac{24}{25}$
  • $\tan\theta = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}} = \frac{24k}{7k} = \frac{24}{7}$
  • $\text{cosec}\theta = \displaystyle\frac{\text{অতিভুজ}}{\text{লম্ব}} = \frac{25k}{24k} = \frac{25}{24}$
  • $\sec\theta = \displaystyle\frac{\text{অতিভুজ}}{\text{ভূমি}} = \frac{25k}{7k} = \frac{25}{7}$
  • $\cot\theta = \displaystyle\frac{\text{ভূমি}}{\text{লম্ব}} = \frac{7k}{24k} = \frac{7}{24}$

5. যদি $\cot\theta = 2$ হয়, তাহলে $\tan\theta$ ও $\sec\theta$-এর মান নির্ণয় করি এবং দেখাই যে, $1+\tan^2\theta = \sec^2\theta$.

সমাধান

দেওয়া আছে, $\cot\theta = 2 = \displaystyle\frac{2}{1}$

আমরা জানি, $\cot\theta = \displaystyle\frac{\text{ভূমি}}{\text{লম্ব}}$।

ধরি, ভূমি $= 2k$ এবং লম্ব $= 1k = k$ (যেখানে $k > 0$)।

পিথাগোরাসের উপপাদ্য অনুযায়ী অতিভুজ-এর দৈর্ঘ্য:

\[ \begin{array}{l} \text{অতিভুজ}^2 = \text{লম্ব}^2 + \text{ভূমি}^2 \\ = k^2 + (2k)^2 \\ = k^2 + 4k^2 = 5k^2 \\ \text{অতিভুজ} = \sqrt{5k^2} = \sqrt{5}k \end{array} \]

$\tan\theta$ এবং $\sec\theta$-এর মান:

$\tan\theta = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}} = \frac{k}{2k} = \frac{1}{2}$

$\sec\theta = \displaystyle\frac{\text{অতিভুজ}}{\text{ভূমি}} = \frac{\sqrt{5}k}{2k} = \frac{\sqrt{5}}{2}$

প্রমাণ (L.H.S = R.H.S):

বামপক্ষ (L.H.S) = $1 + \tan^2\theta$

\[ \begin{array}{l} = 1 + \left(\frac{1}{2}\right)^2 \\ = 1 + \frac{1}{4} = \frac{4+1}{4} = \frac{5}{4} \end{array} \]

ডানপক্ষ (R.H.S) = $\sec^2\theta$

\[ \begin{array}{l} = \left(\frac{\sqrt{5}}{2}\right)^2 \\ = \frac{5}{4} \end{array} \]
বামপক্ষ = ডানপক্ষ (প্রমাণিত)।

6. $\cos\theta = 0.6$ হলে, দেখাই যে, $(5\sin\theta - 3\tan\theta) = 0$.

সমাধান

দেওয়া আছে, $\cos\theta = 0.6 = \displaystyle\frac{6}{10} = \frac{3}{5}$

আমরা জানি, $\cos\theta = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}}$।

ধরি, ভূমি $= 3k$ এবং অতিভুজ $= 5k$ ($k > 0$)।

পিথাগোরাসের উপপাদ্য অনুযায়ী লম্ব-এর দৈর্ঘ্য:

\[ \begin{array}{l} \text{লম্ব}^2 = \text{অতিভুজ}^2 - \text{ভূমি}^2 \\ = (5k)^2 - (3k)^2 \\ = 25k^2 - 9k^2 = 16k^2 \\ \text{লম্ব} = \sqrt{16k^2} = 4k \end{array} \]

এবার প্রয়োজনীয় অনুপাতগুলির মান বের করি:

$\sin\theta = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{4k}{5k} = \frac{4}{5}$

$\tan\theta = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}} = \frac{4k}{3k} = \frac{4}{3}$

বামপক্ষ (L.H.S):

\[ \begin{array}{l} 5\sin\theta - 3\tan\theta = 5\left(\frac{4}{5}\right) - 3\left(\frac{4}{3}\right) \\ = 4 - 4 \\ = 0 \end{array} \]
বামপক্ষ = ডানপক্ষ (প্রমাণিত)।

7. যদি $\cot A = \displaystyle\frac{4}{7.5}$ হয়, তাহলে $\cos A$ এবং $\text{cosec} A$-এর মান নির্ণয় করি এবং দেখাই যে, $1 + \cot^2 A = \text{cosec}^2 A$.

সমাধান

দেওয়া আছে, $\cot A = \displaystyle\frac{4}{7.5}$

দশমিক তুললে পাই: $\cot A = \displaystyle\frac{40}{75} = \frac{8}{15}$ (5 দিয়ে কেটে)।

আমরা জানি, $\cot A = \displaystyle\frac{\text{ভূমি}}{\text{লম্ব}}$।

ধরি, ভূমি $= 8k$ এবং লম্ব $= 15k$ ($k > 0$)।

অতিভুজ-এর দৈর্ঘ্য:

\[ \begin{array}{l} \text{অতিভুজ}^2 = \text{লম্ব}^2 + \text{ভূমি}^2 \\ = (15k)^2 + (8k)^2 \\ = 225k^2 + 64k^2 = 289k^2 \\ \text{অতিভুজ} = \sqrt{289k^2} = 17k \end{array} \]

$\cos A$ এবং $\text{cosec} A$-এর মান:

$\cos A = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}} = \frac{8k}{17k} = \frac{8}{17}$

$\text{cosec} A = \displaystyle\frac{\text{অতিভুজ}}{\text{লম্ব}} = \frac{17k}{15k} = \frac{17}{15}$

প্রমাণ (L.H.S = R.H.S):

বামপক্ষ (L.H.S) = $1 + \cot^2 A$

\[ \begin{array}{l} = 1 + \left(\frac{8}{15}\right)^2 \\ = 1 + \frac{64}{225} = \frac{225+64}{225} = \frac{289}{225} \end{array} \]

ডানপক্ষ (R.H.S) = $\text{cosec}^2 A$

\[ \begin{array}{l} = \left(\frac{17}{15}\right)^2 \\ = \frac{289}{225} \end{array} \]
বামপক্ষ = ডানপক্ষ (প্রমাণিত)।

8. যদি $\sin C = \displaystyle\frac{2}{3}$ হয়, তবে $\cos C \times \text{cosec} C$-এর মান হিসাব করে লিখি।

সমাধান

দেওয়া আছে, $\sin C = \displaystyle\frac{2}{3}$

আমরা জানি, $\sin C = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}}$।

ধরি, লম্ব $= 2k$ এবং অতিভুজ $= 3k$ ($k > 0$)।

ভূমি-এর দৈর্ঘ্য:

\[ \begin{array}{l} \text{ভূমি}^2 = \text{অতিভুজ}^2 - \text{লম্ব}^2 \\ = (3k)^2 - (2k)^2 \\ = 9k^2 - 4k^2 = 5k^2 \\ \text{ভূমি} = \sqrt{5k^2} = \sqrt{5}k \end{array} \]

এখন, $\cos C = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}} = \frac{\sqrt{5}k}{3k} = \frac{\sqrt{5}}{3}$

এবং $\text{cosec} C = \displaystyle\frac{1}{\sin C} = \frac{3}{2}$

প্রদত্ত রাশির মান:

\[ \begin{array}{l} \cos C \times \text{cosec} C = \frac{\sqrt{5}}{3} \times \frac{3}{2} \\ = \frac{\sqrt{5}}{2} \end{array} \]
উত্তর: নির্ণেয় মান $\displaystyle\frac{\sqrt{5}}{2}$

9. নীচের বিবৃতিগুলি সত্য না মিথ্যা তা যুক্তি সহকারে লিখি।

(i) $\tan A$-এর মান সর্বদা 1 অপেক্ষা বড়ো।

যুক্তি: $\tan A = \displaystyle\frac{\text{লম্ব}}{\text{ভূমি}}$। সমকোণী ত্রিভুজে লম্বভূমির চেয়ে বড়ো, ছোটো বা সমান হতে পারে। তাই $\tan A$-এর মান 1 এর চেয়ে বড়ো, ছোটো বা 1 হতে পারে।

মিথ্যা (False)
(ii) $\cot A$-এর মান সর্বদা 1 অপেক্ষা ছোটো।

যুক্তি: $\cot A = \displaystyle\frac{\text{ভূমি}}{\text{লম্ব}}$। সমকোণী ত্রিভুজে ভূমি লম্বের চেয়ে বড়ো হলে $\cot A$ এর মান 1 এর চেয়ে বড়ো হতে পারে। তাই সর্বদা 1 অপেক্ষা ছোটো নয়।

মিথ্যা (False)
(iii) একটি কোণ $\theta$-এর জন্য $\sin\theta = \displaystyle\frac{4}{3}$ হতে পারে।

যুক্তি: $\sin\theta = \displaystyle\frac{\text{লম্ব}}{\text{অতিভুজ}}$। একটি সমকোণী ত্রিভুজে অতিভুজ সর্বদা বৃহত্তম বাহু হয়, অর্থাৎ লম্ব কখনোই অতিভুজের চেয়ে বড়ো হতে পারে না। তাই $\sin\theta$ এর মান কখনোই 1 এর চেয়ে বড়ো হতে পারে না ($\frac{4}{3} > 1$)।

মিথ্যা (False)
(iv) একটি কোণ $\alpha$-এর জন্য $\sec\alpha = \displaystyle\frac{12}{5}$ হতে পারে।

যুক্তি: $\sec\alpha = \displaystyle\frac{\text{অতিভুজ}}{\text{ভূমি}}$। অতিভুজ সর্বদা ভূমির চেয়ে বড়ো হয়, তাই $\sec\alpha$-এর মান সর্বদা 1 এর চেয়ে বড়ো হয়। এখানে $\frac{12}{5} > 1$, তাই এটি সম্ভব।

সত্য (True)
(v) একটি কোণ $\beta$(Beta)-এর জন্য $\text{cosec}\beta = \displaystyle\frac{5}{13}$ হতে পারে।

যুক্তি: $\text{cosec}\beta = \displaystyle\frac{\text{অতিভুজ}}{\text{লম্ব}}$। অতিভুজ লম্বের চেয়ে বড়ো হওয়ায় $\text{cosec}\beta$-এর মান সর্বদা 1 এর চেয়ে বড়ো হয়। কিন্তু এখানে $\frac{5}{13} < 1$, যা অসম্ভব।

মিথ্যা (False)
(vi) একটি কোণ $\theta$-এর জন্য $\cos\theta = \displaystyle\frac{3}{5}$ হতে পারে।

যুক্তি: $\cos\theta = \displaystyle\frac{\text{ভূমি}}{\text{অতিভুজ}}$। অতিভুজ ভূমির চেয়ে বড়ো হওয়ায় $\cos\theta$ এর মান সর্বদা 1 এর চেয়ে ছোটো বা 1 এর সমান হয়। এখানে $\frac{3}{5} < 1$, তাই এটি সম্ভব।
