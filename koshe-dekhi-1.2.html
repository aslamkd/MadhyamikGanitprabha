1. নীচের প্রতিক্ষেত্রে প্রদত্ত মানগুলি প্রদত্ত দ্বিঘাত সমীকরণের বীজ কিনা যাচাই করে লিখি:

(i) $x^2 + x + 1 = 0$; $1$ ও $-1$
সমাধান

প্রদত্ত সমীকরণের বামপক্ষে $x = 1$ বসিয়ে পাই:

$$ 1^2 + 1 + 1 = 1 + 1 + 1 = 3 \neq 0 $$

আবার, বামপক্ষে $x = -1$ বসিয়ে পাই:

$$ (-1)^2 + (-1) + 1 = 1 - 1 + 1 = 1 \neq 0 $$

উত্তর: 1 ও -1 প্রদত্ত সমীকরণের বীজ নয়।
(ii) $8x^2 + 7x = 0$; $0$ ও $-2$
সমাধান

সমীকরণের বামপক্ষে $x = 0$ বসিয়ে পাই:

$$ 8(0)^2 + 7(0) = 0 + 0 = 0 $$

সুতরাং, 0 সমীকরণটির একটি বীজ।

আবার, বামপক্ষে $x = -2$ বসিয়ে পাই:

$$ 8(-2)^2 + 7(-2) = 8(4) - 14 = 32 - 14 = 18 \neq 0 $$

উত্তর: 0 প্রদত্ত সমীকরণের বীজ কিন্তু -2 সমীকরণের বীজ নয়।
(iii) $\displaystyle x + \frac{1}{x} = \frac{13}{6}$; $\displaystyle\frac{5}{6}$ ও $\displaystyle\frac{4}{3}$
সমাধান

বামপক্ষে $\displaystyle x = \frac{5}{6}$ বসিয়ে পাই:

$$ \frac{5}{6} + \frac{1}{\frac{5}{6}} = \frac{5}{6} + \frac{6}{5} = \frac{25+36}{30} = \frac{61}{30} \neq \frac{13}{6} $$

বামপক্ষে $\displaystyle x = \frac{4}{3}$ বসিয়ে পাই:

$$ \frac{4}{3} + \frac{1}{\frac{4}{3}} = \frac{4}{3} + \frac{3}{4} = \frac{16+9}{12} = \frac{25}{12} \neq \frac{13}{6} $$

উত্তর: $\displaystyle\frac{5}{6}$ ও $\displaystyle\frac{4}{3}$ সমীকরণের বীজ নয়।
(iv) $x^2 - \sqrt{3}x - 6 = 0$; $-\sqrt{3}$ ও $2\sqrt{3}$
সমাধান

বামপক্ষে $x = -\sqrt{3}$ বসিয়ে পাই:

$$ (-\sqrt{3})^2 - \sqrt{3}(-\sqrt{3}) - 6 = 3 + (\sqrt{3} \times \sqrt{3}) - 6 = 3 + 3 - 6 = 0 $$

বামপক্ষে $x = 2\sqrt{3}$ বসিয়ে পাই:

$$ (2\sqrt{3})^2 - \sqrt{3}(2\sqrt{3}) - 6 = (4 \times 3) - (2 \times 3) - 6 = 12 - 6 - 6 = 0 $$

উত্তর: $-\sqrt{3}$ এবং $2\sqrt{3}$ উভয়েই প্রদত্ত সমীকরণের বীজ।

2. বীজ নির্ণয় ও যাচাই:

(i) k-এর কোন মানের জন্য $7x^2 + kx - 3 = 0$ দ্বিঘাত সমীকরণের একটি বীজ $\displaystyle\frac{2}{3}$ হবে হিসাব করে লিখি।
সমাধান

যেহেতু $\displaystyle x = \frac{2}{3}$ সমীকরণটির একটি বীজ, তাই এটি সমীকরণটিকে সিদ্ধ করবে।

সমীকরণে $\displaystyle x = \frac{2}{3}$ বসিয়ে পাই:

\[ \begin{array}{l} 7\left(\frac{2}{3}\right)^2 + k\left(\frac{2}{3}\right) - 3 = 0 \\ 7\left(\frac{4}{9}\right) + \frac{2k}{3} - 3 = 0 \\ \frac{28}{9} + \frac{2k}{3} - 3 = 0 \end{array} \]

ল.সা.গু. 9 করে পাই:

\[ \begin{array}{l} \frac{28 + 6k - 27}{9} = 0 \\ 1 + 6k = 0 \\ 6k = -1 \\ k = -\frac{1}{6} \end{array} \]
উত্তর: k-এর নির্ণেয় মান $-\frac{1}{6}$
(ii) k-এর কোন মানের জন্য $x^2 + 3ax + k = 0$ দ্বিঘাত সমীকরণের একটি বীজ $-a$ হবে হিসাব করে লিখি।
সমাধান

যেহেতু $x = -a$ সমীকরণটির একটি বীজ, তাই এটি সমীকরণটিকে সিদ্ধ করবে।

সমীকরণে $x = -a$ বসিয়ে পাই:

\[ \begin{array}{l} (-a)^2 + 3a(-a) + k = 0 \\ a^2 - 3a^2 + k = 0 \\ -2a^2 + k = 0 \\ k = 2a^2 \end{array} \]
উত্তর: k-এর নির্ণেয় মান $2a^2$

3. যদি $ax^2 + 7x + b = 0$ দ্বিঘাত সমীকরণের দুটি বীজ $\displaystyle\frac{2}{3}$ এবং $-3$ হয় তবে a ও b-এর মান নির্ণয় করি।

সমাধান

যেহেতু $\displaystyle x = \frac{2}{3}$ একটি বীজ, সমীকরণে বসিয়ে পাই:

\[ \begin{array}{l} a\left(\frac{2}{3}\right)^2 + 7\left(\frac{2}{3}\right) + b = 0 \\ \frac{4a}{9} + \frac{14}{3} + b = 0 \\ \frac{4a + 42 + 9b}{9} = 0 \\ 4a + 9b + 42 = 0 \quad \text{------ (১ নং সমীকরণ)} \end{array} \]

আবার, যেহেতু $x = -3$ অপর একটি বীজ, সমীকরণে বসিয়ে পাই:

\[ \begin{array}{l} a(-3)^2 + 7(-3) + b = 0 \\ 9a - 21 + b = 0 \\ b = 21 - 9a \quad \text{------ (২ নং সমীকরণ)} \end{array} \]

(২) নং থেকে b এর মান (১) নং সমীকরণে বসিয়ে পাই:

\[ \begin{array}{l} 4a + 9(21 - 9a) + 42 = 0 \\ 4a + 189 - 81a + 42 = 0 \\ -77a + 231 = 0 \\ 77a = 231 \\ a = \frac{231}{77} = 3 \end{array} \]

এবার $a = 3$ মানটি (২) নং সমীকরণে বসিয়ে পাই:

\[ \begin{array}{l} b = 21 - 9(3) \\ b = 21 - 27 = -6 \end{array} \]
উত্তর: $a = 3$ এবং $b = -6$

উভয়পক্ষকে $b$ দিয়ে ভাগ করে ($b \neq 0$ ধরে):

সমাধান

পদগুলিকে ভেঙে লিখলে পাই (Telescoping Series):

\[ \begin{array}{l} \left(\frac{1}{x-2} - \frac{1}{x-1}\right) + \left(\frac{1}{x-3} - \frac{1}{x-2}\right) + \left(\frac{1}{x-4} - \frac{1}{x-3}\right) = \frac{1}{6} \end{array} \]

মাঝের পদগুলো কেটে যায়, ফলে থাকে:

\[ \begin{array}{l} \frac{1}{x-4} - \frac{1}{x-1} = \frac{1}{6} \\ \frac{x-1 - (x-4)}{(x-4)(x-1)} = \frac{1}{6} \\ \frac{3}{x^2 - 5x + 4} = \frac{1}{6} \\ x^2 - 5x + 4 = 18 \\ x^2 - 5x - 14 = 0 \\ (x - 7)(x + 2) = 0 \end{array} \]

হয় $x - 7 = 0 \implies x = 7$, অথবা $x + 2 = 0 \implies x = -2$

নির্ণেয় সমাধান: $x = 7, -2$

ডানপক্ষকে ভেঙে দুই দিকে ভাগ করে দিই:

\[ \begin{array}{l} \left(\frac{a}{x-a} - \frac{c}{x-c}\right) + \left(\frac{b}{x-b} - \frac{c}{x-c}\right) = 0 \\ \frac{ax-ac-cx+ac}{(x-a)(x-c)} + \frac{bx-bc-cx+bc}{(x-b)(x-c)} = 0 \\ \frac{x(a-c)}{(x-a)(x-c)} + \frac{x(b-c)}{(x-b)(x-c)} = 0 \\ x \cdot \left[ \frac{a-c}{(x-a)(x-c)} + \frac{b-c}{(x-b)(x-c)} \right] = 0 \end{array} \]

হয় $x = 0$

অথবা, বন্ধনীর ভেতরের অংশ শূন্য: $\displaystyle\frac{a-c}{(x-a)(x-c)} + \frac{b-c}{(x-b)(x-c)} = 0$

উভয়পক্ষকে $(x-c)$ দিয়ে গুণ করে পাই (যেহেতু $x \neq c$):

\[ \begin{array}{l} \frac{a-c}{x-a} + \frac{b-c}{x-b} = 0 \\ \frac{a-c}{x-a} = \frac{c-b}{x-b} \\ (a-c)(x-b) = (c-b)(x-a) \\ ax - ab - cx + bc = cx - ac - bx + ab \\ ax + bx - 2cx = 2ab - ac - bc \\ x(a+b-2c) = 2ab - ac - bc \\ x = \frac{2ab-ac-bc}{a+b-2c} \end{array} \]
নির্ণেয় সমাধান: $\displaystyle x = 0, \frac{2ab-ac-bc}{a+b-2c}$
